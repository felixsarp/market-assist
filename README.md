# 🛒 Market Assist

A mobile-first PWA for tracking your market shopping list. Built with React + Vite.

## Features
- ✅ Tap any item to mark as bought
- 💰 Enter actual price paid per item
- ➕ Add items not on the default list
- 🗑️ Delete any item (preset or custom)
- 💾 Auto-saves to device storage
- 📱 Installable as a mobile app (PWA)
- 🔌 Works offline
